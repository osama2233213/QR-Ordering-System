# Frontend — QuickServe Restaurant System

Vite + React 18 + Tailwind CSS single frontend hosting 3 dedicated app zones:
1. **Customer Mobile Experience** (`/r/:restaurantId/t/:tableId`)
2. **Restaurant Admin & Kitchen Queue** (`/admin/*`)
3. **DevGate Super-Admin Panel** (`/devgate/*`)
4. **Dev Launcher Hub** (`/`)
